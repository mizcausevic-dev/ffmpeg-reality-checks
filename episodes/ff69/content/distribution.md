### Description

You write adelay=1000 on a stereo clip and expect both channels to start a second late. Only the left one does. The right channel plays at once. We test ten settings on a synthetic stereo file and read every channel two ways.

Input (lavfi aevalsrc, 1 file): stereo, 48000 Hz, 2 s (96000 frames), 16 bit wav. Left is a 440 Hz sine, right is a 660 Hz sine, both with a start phase of 1 rad so the first sample is not zero. Ten outputs: no filter (control), adelay=1000, 1000|1000, 1000:all=1, 1000|0, 0|1000, 500|1500, 1000|1000|1000, 48000S and 333|777.

Readers: (1) Node parses the RIFF chunks of each output and scans the int16 samples of each channel: first non zero sample, trailing run of zeros, frame count, and whether the delayed channel is an exact copy of the input shifted by its delay. (2) ffmpeg splits each channel with pan and runs silencedetect (noise -70 dB, d 0.005 s): the end of a silence that starts at 0 is the onset, a silence that reaches the end of the file is the tail.

Control and known positive: with no filter both channels start at sample 0 (both readers). A file whose left channel is gated by an expression to start at 0.25 s reads 12000 and 0 in both readers.

adelay=1000: left starts at sample 48000 (1.000 s), right starts at sample 0. The right channel is not shortened: it ends with 48000 zeros, and both channels are 144000 frames (3.000 s). The first left samples are 0, 0, 0, 13787, 14273, 14713 at indexes 47997 to 48002; the delayed channel is an exact copy of the input in all 10 files.

One value per channel: 1000|1000, 1000:all=1 and 1000|1000|1000 (a list longer than the channel count) all start both channels at sample 48000 with no tail, and have identical 20 ms peak envelopes. 1000|0 and 48000S are identical to a single 1000. 0|1000 delays only the right channel (onset 0 and 48000, left tail 48000). 500|1500 gives onsets 24000 and 72000, and 333|777 gives 15984 and 37296.

Length rule: in all 10 files the output has the input length plus the largest delay (96000 + 48000 = 144000; 168000 for 500|1500; 133296 for 333|777), and each channel ends with the difference as zeros. Delays are in milliseconds unless the S suffix is used (1000 ms = 48000 samples).

The 13 tests pass on ffmpeg 6.1.1.
