### Description

You have two clips of different sizes and you join them with the FFmpeg concat demuxer and -c copy. Does FFmpeg stop you or warn you? We build two synthetic clips and look inside the result.

The clips: A is 320x180 and B is 640x360, each 2 seconds at 25 fps, 50 frames. The FFmpeg docs say that for the concat demuxer "All files must have the same streams (same codecs, same time base, etc.)." We break that on purpose.

The join: ffmpeg -f concat -i mixed.txt -c copy out.mp4 exits with code 0 and prints 0 warning lines. ffprobe says the file is 320x180, 100 frames, 4 seconds. Decoding every frame and reading its size shows 50 frames at 320x180 and 50 frames at 640x360. Decoding with ffmpeg reports 0 problems; whether a player copes was not tested.

Controls: two clips of the same size joined with -c copy give 100 frames, all 320x180. Re-encoding the mixed pair with scale=640:360:force_original_aspect_ratio=decrease, pad=640:360 and setsar=1 gives 100 frames, all 640x360, and the header agrees.

Results were identical on ffmpeg 6.1.1 and 8.1.2.
