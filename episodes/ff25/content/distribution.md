### Description

You grab one thumbnail per second with -vf fps=1. Which frame do you get from each second: the first, at 0, 1, 2 seconds? We mark every frame of a synthetic clip and read which ones come out.

Sources (lavfi color + geq, gray 64x64, stored losslessly): frame N has luma value N. 25 fps for 5 s (125 frames), 30 fps for 5 s (150 frames) and 60 fps for 2 s (120 frames).

Readers: frame md5 matched back to the source, and the decoded luma value of each output frame (which is the frame number). They agree on every output.

25 fps, fps=1: keeps source frames 12, 37, 62, 87, 112. The first thumbnail is at 0.48 s, not 0. 30 fps: frames 14, 44, 74, 104, 134 (0.467 s). The default rounding picks the frame in the middle of each second.

fps=1:round=up keeps the first frame of each second (0, 25, 50, 75, 100). round=down keeps the last (24, 49, 74, 99, 124). select='not(mod(n,25))' with -fps_mode vfr also keeps 0, 25, 50, 75, 100.

60 fps to 24 fps with fps=24: 48 frames out, the first source frame is never used, and the kept frames are 1, 3, 6, 8, 11, 13 (steps of 2 and 3).

The seven tests pass on ffmpeg 6.1.1 and 8.1.2.
