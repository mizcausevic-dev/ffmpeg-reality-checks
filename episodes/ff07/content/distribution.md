### Description

You want a file at -14 LUFS and you run the FFmpeg loudnorm filter once. Does the output land on -14? Does a second, measured pass do better? We make a test tone, run both ways, and measure the written files with a separate tool.

The source is synthetic: a 440 Hz tone at -10 dB for 8 seconds, then -2 dB for 8 seconds, 48 kHz. Measured with the ebur128 filter: integrated -26.1 LUFS, loudness range 8 LU, peak -20.1 dBFS. The target was I=-14, TP=-1.5, LRA=11.

One pass: integrated -11.7 LUFS, range 4.5 LU, peak -3.9 dBFS. That is 2.3 LU louder than the target. loudnorm's own report said output -11.76 LUFS, range 4.1 LU, mode dynamic.

Two pass (measured values fed back, linear=true): integrated -14.5 LUFS, range 8 LU, peak -8.4 dBFS. That is 0.5 LU from the target. The second run reported mode linear.

Numbers were identical on ffmpeg 6.1.1 and 8.1.2.
